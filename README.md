# WAHY LAB SOLUTIONS – TECHNOLOGICAL SKILL GAP ANALYSIS

## Project Overview

This project studies technological skill gaps and their impact on employee performance at Wahy Lab Solutions, Kochi, Kerala, using a Business Analytics approach.

## Objectives

1. Identify technological skill gaps among employees and interns.
2. Examine the relationship between technological skills and employee performance.
3. Assess the role of technical training, mentor guidance and learning opportunities.
4. Compare performance patterns between employees and interns.
5. Analyse and visualize skill-gap, training and performance data using Business Analytics tools.

## Tools Used

- Excel
- SQL
- Python
- Power BI

## Dataset

The study is based on **100 questionnaire responses** collected from employees and interns.

## Analysis Performed

- Descriptive Statistics
- Mean and Standard Deviation
- Pearson Correlation
- Independent Samples t-test
- Chi-square Test
- One-way ANOVA
- Data Visualization
- Power BI Dashboard

## Files Included

### SQL Analysis
`Wahy_Skill_Gap_COMPLETE_SQL.sql`

Contains SQL table creation, data insertion and analytical queries.

### Python Analysis
`Wahy_Skill_Gap_COMPLETE_PYTHON.py`

Contains data analysis, statistical tests and analytical calculations.

## Key Results

- Technological Skill Score: **3.42**
- Training / Support Score: **3.27**
- Performance Score: **3.41**
- Skill–Performance Correlation: **0.9236**
- Training/Support–Performance Correlation: **0.9141**
- Employee Average Performance: **3.54**
- Intern Average Performance: **3.27**

## Power BI Dashboard

A Power BI dashboard was developed to visualize technological skills, training/support and employee performance.

## Conclusion

The analysis indicates a strong positive relationship between technological skills, training/support and employee performance. The project demonstrates how Business Analytics tools can be used to identify skill-related patterns and generate useful insights for employee development.
